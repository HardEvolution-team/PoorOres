# Poor Ores Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **PoorOres** by Xexanos.

- Original: https://www.curseforge.com/minecraft/mc-mods/poorores
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.35.0+

This port contains **no original assets**. Put your own copy of the original jar (`PoorOres_1.7.10_1.4.2.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
